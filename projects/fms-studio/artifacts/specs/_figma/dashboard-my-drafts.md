## Layout and Sections
- **Top Navigation Bar**: Logo, "Dashboard" link, credits counter, "Buy Credits" button, and user profile dropdown.
- **Left Sidebar**: Icon navigation with four icons (Album, Layout Dashboard, Square Pen, Settings) and a user avatar at the bottom.
- **Main Content Area**:
  - Header with greeting: "Good Morning, Dream Marathon Org!"
  - Search bar in the top right of the main content area (Search input).
  - Section title: "My Drafts" with a "Top Up +" button next to it.
  - A grid of draft cards.

## Elements
1. **Top Navigation**:
   - Link: "Dashboard"
   - Read-only pill: "420 Credits" (orange text, orange dot).
   - Button: "Buy Credits" (solid orange).
   - User profile dropdown: Avatar image and chevron-down icon.

2. **Left Sidebar**:
   - Icon links: `album`, `layout-dashboard`, `square-pen`, `settings`.
   - Bottom avatar image.

3. **Header**:
   - Title text: "Good Morning, Dream Marathon Org!"
   - Search input: Placeholder "Search", magnifying glass icon.

4. **Section Header**:
   - Title: "My Drafts"
   - Button: "Top Up +" (solid orange, plus icon).

5. **Draft Cards Grid**:
   - **Create New Album Card**:
     - Light grey square container.
     - Large `plus` icon.
     - Text: "Create New Album".
   - **Existing Draft Cards** (e.g., "Nike Run 2026", "Fun Run Marathon"):
     - Image thumbnail placeholder (`image` icon).
     - Event Title (e.g., "Nike Run 2026").
     - Button: "Publish" (solid orange).
     - Three-dot menu icon in the top left of the card.

## Visuals
- Fonts: Host Grotesk.
- Brand color: Orange (`#FF6100`).

- Card backgrounds: Light grey `#F7F6F6`.
- Draft card overlay gradient: Linear gradient white to grey.
