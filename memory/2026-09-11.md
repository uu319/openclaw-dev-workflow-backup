## 2026-09-10 to 2026-09-11 System Incidents

- **Figma MCP Memory Leak**: The `figma-developer-mcp` server is leaking memory and spawning duplicate zombie processes. This caused the kernel's OOM (Out of Memory) killer to repeatedly terminate OpenClaw gateway processes on Sept 10 and 11 when memory hit the ~1.6GB limit. I disabled the MCP server in `openclaw.json` (`openclaw mcp unset figma`) and restarted the gateway to mitigate the issue. <!-- project: path:/home/openclaw/.openclaw/workspace -->
- **Gateway Restart-Loop Breaker**: The repeated OOM killer terminations triggered OpenClaw's restart-loop breaker. This successfully prevented further rapid crashes, but intentionally left all channel bots (Discord and Telegram) in a `stopped` state upon the final gateway recovery to preserve system stability. I manually restarted all 8 channel accounts using `openclaw gateway call channels.start` to bring them back online. <!-- project: path:/home/openclaw/.openclaw/workspace -->
